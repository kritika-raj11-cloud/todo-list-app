# To-Do List App
A simple full-stack To-Do List application built to manage daily tasks.

# Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Save tasks in a local JSON file
- Responsive user interface

# Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- JSON file storage

# Installation and Setup
1. Install Node.js.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Install dependencies:
   `npm install`
5. Start the server:
   `npm start`
6. Open http://localhost:5000 in your browser.

# Storage
Tasks are stored locally in `tasks.json`.
